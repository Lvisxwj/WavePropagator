# SMILE²: Spectral-Field Estimation and Evolution for CASSI Reconstruction

This repository contains the SMILE² research code and the English AAAI manuscript draft for snapshot compressive spectral imaging reconstruction.

## Contents

- `src/repo/`: model, training, testing, configuration, and analysis code.
- `src/tools/`: public evaluation / figure helper scripts.
- `paper/aaai2027/`: English LaTeX manuscript, bibliography, PDF draft, figures, and the official AAAI author kit under `author_kit/`.
- `logic/`: research notes used to track problem formulation, claims, and method design.
- `evidence/`: selected public figures and result tables.

## Privacy note

Server-specific launch scripts, private paths, logs, datasets, and checkpoints are intentionally excluded from this public-review package.
