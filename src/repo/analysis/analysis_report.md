# E207 Capacity 光谱机制分析（阶段性报告）

分析对象：`[2,4,4] + full WPO + FFN` 的 E207 best checkpoint。所有实验均为
post-hoc 诊断，不更新模型参数。

## 1. 解析 PDE 频率响应

- 16 个 WPO 层的平均频率响应不是常数，说明学习结果没有退化成恒等映射。
- 其等效谱域核主要集中在零偏移及相邻偏移，但仍存在较弱长程尾部。
- 响应存在不完全对称，可能与 FFT 后逐模态 `alpha/vs` 没有显式共轭对称约束有关。
  在完成实现审计前，不宜将该图直接解释为严格物理频响。

## 2. 完整 backbone 有限差分混合图

- 对角响应占约 **34.8%**。
- 相邻 ±2 的非对角响应累计占约 **14.4%**。
- 更远位置单项响应较弱，但因位置数量多，累计约 **50.8%**。

因此，完整网络表现为“本波段主导、局部强耦合、分布式全局补充”，而不是纯粹的
邻域插值。该结果支持结构化跨波段传播，但不能声称模型只依赖邻近波段。

## 3. 目标波段贡献移除

- 完整测量下，平均目标波段 PSNR：**35.72 dB**。
- 移除目标波段自身测量贡献后：**27.95 dB**。

模型在完全看不到目标波段直接贡献时仍可恢复到约 28 dB，说明其确实利用其他波段
进行补偿。不过下降约 7.78 dB 也说明直接观测仍然不可替代。

原始 `near-only/far-only` 对照的波段数量不一致，只保留作探索结果，不应用于论文结论。

## 4. 等数量邻近/远端遮挡

从“目标波段已移除”的同一基线出发：

| 条件 | 平均目标波段 PSNR |
|---|---:|
| 仅移除目标波段 | 27.948 dB |
| 再移除 K 个邻近波段 | 22.748 dB |
| 再移除 K 个远端波段（8组匹配平均） | 23.422 dB |

- 移除邻近波段造成平均 **5.200 dB** 下降。
- 移除等数量远端波段造成平均 **4.526 dB** 下降。
- 邻近波段平均重要性高 **0.674 dB**。
- 在 280 个 scene-band 配对中，邻近更重要的比例为 **56.8%**。
- 以10个scene分别聚合后，均值差的探索性95%区间约为 **[0.013, 1.335] dB**。

该证据是“邻近信息总体略重要”的支持，而不是压倒性结论。波段 4–17 中，移除远端
波段反而往往造成更大下降；光谱两端及高编号波段对邻近信息更敏感。这说明模型学习到
的是随光谱区域变化的局部—全局混合，而非统一的局部平滑规律。

## 5. 论文使用建议

可以支撑：

> SWAP 利用高光谱冗余形成结构化跨波段传播，其响应以本波段和局部耦合为主，同时保留
> 弱而广泛的长程光谱联系。

不应声称：

- 每个波段都主要由相邻波段恢复；
- PDE 显式学习了一个固定的波段线性组合矩阵；
- 当前频率响应已经满足严格物理系统的共轭对称性；
- 等数量即等信息量。实验记录了移除测量能量，但没有强制能量完全匹配。

主文候选：经验混合矩阵 + 等数量遮挡图。解析频响在解决/解释不对称性前更适合放附录
或内部诊断。
