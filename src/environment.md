# Environment and Reproducibility Notes

Main local workspace was developed on Windows/PowerShell. Main large-scale training and evaluation used NVIDIA A800 GPUs with 80GB memory.

Core code is under `src/repo/`. Paper source is under `paper/aaai2027/`.

Legacy DU code and external SOTA repositories are intentionally not copied into the main clean project by default. They should be archived separately if needed for future CVPR/DU work.
