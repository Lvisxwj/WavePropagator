# Environment

The code is implemented with PyTorch and targets CUDA-enabled GPUs. The exact environment can be adapted to the local machine; paths in configuration files should be changed to point to local datasets and checkpoints.

Recommended runtime components:

- Python 3.8+
- PyTorch with CUDA support
- NumPy, SciPy, scikit-image, PyYAML, tqdm
- Matplotlib for visualization scripts

Datasets and pretrained checkpoints are not bundled in this review package.
