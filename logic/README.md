# Logic layer index

This folder is the source of truth for paper reasoning and notation.

- `problem.md` — problem definition, CASSI difficulty, E2E positioning, and boundary against DU-style claims.
- `concepts.md` — method names, term definitions, and what should/should not be claimed.
- `algorithm.md` — mathematical notation, forward model, CASSI Prep, SFEstimator/SFEvolver flow, SWP derivation, and loss.
- `claims.md` — paper claims and supporting evidence.

Use this folder before editing figures or LaTeX. In particular, symbols such as `Y`, `M`, `Phi`, `H0`, `Q0`, `U1`, and `U2` should match `algorithm.md`.
