# SMILE²-M checkpoint

This folder contains the released SMILE²-M checkpoint used by the paper-facing evaluation scripts.

- `SMILE-M_best_psnr.pth`: best-PSNR checkpoint.
- `metrics.csv`: training/evaluation log snapshot.
- `status.json`: compact checkpoint metadata.
- `SOURCE.txt`: original local provenance note.

Use with `src/repo/configs/smile_m.yaml`.
