# Evidence layer index

This folder stores result-bearing artifacts used to support the paper.

- `checkpoints/` — SMILE-S/M/L checkpoint backups and checkpoint provenance notes.
- `results/` — SOTA table, ablation table, per-scene CSVs, citation planning, and narrative support notes.
- `figures/` — generated visual evidence and non-final figure outputs.

Rules:

- Use CSV/table files here when updating the paper; do not rely on memory.
- Keep unfinished or diagnostic figures here unless they are explicitly copied into `paper/aaai2027/figures/final/`.
- If a result is from a partial run or external paper table, record the source in the corresponding result note or caption draft.
